# ❤️ 3D Glowing Love Heart

An animated romantic web project featuring a **3D glowing heart**, particle heart formation, floating hearts, animated background, glowing “I Love You” text, and a music button.

## ✨ Features

* 🌌 Dark animated gradient background
* ✨ Glowing particles
* 💕 Particles form a heart shape
* ❤️ 3D glowing heart animation
* 💓 Heartbeat effect
* 💕 Animated **“I Love You”** text
* ✨ Continuously floating hearts
* 🎵 Music play/pause button
* 📱 Mobile-friendly responsive design
* ⚡ Built with pure HTML, CSS & JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML Canvas
* CSS Animations

## 📁 Project Structure

```text
3D-Love-Heart/
│
├── index.html
├── style.css
├── script.js
└── love.mp3
```

## 🚀 How to Run

1. Download or clone the project.
2. Keep all files in the same folder.
3. Add your music file and rename it to `love.mp3`.
4. Open `index.html` in any modern web browser.
5. Enjoy the animation ❤️
